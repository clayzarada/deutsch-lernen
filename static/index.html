About you

AI costs

When this month's estimated spending reaches the budget, Claude features pause until the 1st. Save settings to apply.

Backups

The app backs up your progress automatically once a day and keeps the last 14. Restoring first backs up what you have now, so it can be undone.

Backup file

Everything in one file (progress, cards, answers, books and audio) to keep somewhere safe or move to another computer. Your API keys aren't included.
